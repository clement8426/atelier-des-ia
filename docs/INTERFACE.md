# Contrat de l’interface

Public : personnes qui découvrent les IA, sans connaissance du développement.
Usage : choisir une expérience, préparer les ressources, lancer un calcul réel et comprendre sa limite.
Direction : carnet d’exploration contemporain, fond ivoire, encre sombre, accents orange, vert et bleu. Une barre latérale stable, une numérotation de parcours et de vraies images d’exemple ; pas de page marketing avant les ateliers.

Action principale : « Essayer » puis « Télécharger et tester » si les ressources manquent. Un seul calcul actif, annulation visible. Les informations techniques sont repliées.
Écrans à vérifier : 1440×900 et 900×720 ; repli à 600 px pour agrandissement et fenêtres étroites. Contrôles au clavier, focus visible, contrastes, réduction des animations.

| État       | Déclencheur                        | Retour visible et action                                          |
| ---------- | ---------------------------------- | ----------------------------------------------------------------- |
| Chargement | Diagnostic, téléchargement, calcul | Texte de progression, bouton d’annulation pour les tâches longues |
| Vide       | Modèle absent                      | Taille annoncée et préparation proposée                           |
| Erreur     | Réseau, intégrité, calcul          | Message compréhensible, réessayer ou revenir                      |
| Partiel    | Certains ateliers préparés         | Statut individuel, les autres restent accessibles                 |
| Succès     | Calcul terminé                     | Sortie réelle, temps mesuré, prochaine expérience                 |
| Permission | Aucun capteur dans le socle        | Sans objet pour cette version, pas de demande caméra/microphone   |

Référence produit : besoins et plan validés, exemples de cours et interface locale. Aucun service de design externe utilisé.
