# Maintenance

- Lire README.md et docs/VALIDATION.md avant une modification.
- L’interface et le README s’adressent à des non-développeurs. Réserver les détails de programmation à docs/DEVELOPPEMENT.md.
- Actualiser la documentation concernée avec le code. Ne jamais présenter un candidat, une simulation ou une capture comme une capacité mesurée.
- Garder les calculs locaux, les versions épinglées et les empreintes vérifiées. Aucun code de modèle téléchargé et exécuté.
- Tester les frontières utiles : fichiers, import, annulation, IPC et véritables inférences. Ne pas ajouter de tests qui recopient simplement le JSX.
- Avant livraison, TypeScript, tests unitaires et tests Electron ; signaler clairement les plateformes et machines non testées.
